# Código de conducta

Mírame nace para ayudar a predicadores a mejorar. Queremos que el espacio alrededor del proyecto (issues, pull requests, discusiones) sea respetuoso con todos, sin importar su tradición, experiencia técnica u origen.

## Lo que esperamos

- Tratar a los demás con respeto y buena fe, también al discrepar.
- Criticar el código y las ideas, no a las personas.
- Ser cuidadosos con los videos y datos de terceros: no compartir sermones privados ni datos personales sin permiso.
- Aceptar con humildad las correcciones y dar crédito a quien aporta.

## Lo que no se acepta

- Insultos, burlas o ataques personales, incluidos los dirigidos a predicadores cuyos sermones se analizan.
- Acoso, en público o en privado.
- Publicar información privada de otra persona.

## Cómo se aplica

Quien mantiene el proyecto puede editar o borrar comentarios y contribuciones que no respeten este código, y bloquear a quien insista. Para reportar una situación, escribe en privado desde el perfil de GitHub de [@jacomv](https://github.com/jacomv).
